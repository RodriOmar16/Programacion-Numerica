Desde mi_rama: 
 - Sincronizar mi_rama con el repositorio remoto (origin/mi_rama): git pull origin mi_rama
 - Traer los cambios de master a mi_rama: git pull origin main
 - Cambiar de rama a master: git checkout master
Desde master:
 - Sincronizar master local con origin/master: git pull origin master
 - Fusionar mi_rama dentro de master: git merge mi_rama o bien git rebase mi_rama
 - Enviar los cambios de la master local a la origin/main: git push origin main
